# Todo App 📝

A clean, modern, and fully responsive To-Do application built with React. This project demonstrates core React concepts including state management, component structure, and dynamic UI rendering.

## ✨ Features

* **Add Tasks:** Quickly add new tasks to your list.
* **Mark as Complete:** Toggle individual tasks as done with clear visual feedback (strikethrough and opacity changes).
* **Mark All Done:** Convenient one-click option to complete all active tasks.
* **Delete Tasks:** Remove unwanted tasks from the list.
* **Empty State Prevention:** Form validation prevents adding blank tasks.
* **Modern UI:** Styled with pure CSS featuring flexbox layouts, soft shadows, and smooth hover transitions.

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Build Tool:** Vite
* **Styling:** Custom CSS3 (Flexbox, CSS variables, transitions)
* **Unique IDs:** Native Web Crypto API (`crypto.randomUUID()`)
